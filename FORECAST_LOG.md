# Forecast Log — Pittsburg NH, Aug 11–14 2026

Updated hourly by cron. Newest entry first.

**Watch how a given night moves as lead time shortens.** A night that holds steady across several days is a real signal; one that swings 40 points between runs is telling you the model doesn't know yet.

Sky cover is the number that matters — **PoP is not a cloud forecast.** An overcast rainless night reads 0% precipitation and is a total loss.

**Decision point: Aug 8.** Pivot night is **Aug 12/13** — Perseid maximum and new moon. Go if the core window looks under ~30% cloud.
